# P0 戰鬥 UI／UX 規格

## 目標

手機上的主要操作不是逐張搬牌，而是：

```text
先整理 13 張牌
→ 選出一組 3 張或 5 張
→ 一次放入指定墩位
→ 檢查三墩順序
→ 確認戰鬥
```

## 手牌排序

排序只改變畫面排列，不改變牌的實體身份、抽牌順序或牌陣位置。

提供三種排序：

1. **原始牌序**：依抽牌順序，方便回到最初狀態。
2. **依點數**：A、2～10、J、Q、K；同點數維持原始牌序。
3. **依花色／點數**：水、火、風、地，再依點數排列；同牌維持原始牌序。

手機上使用一個清楚的排序列，不使用藏在選單裡的排序功能：

```text
排序：原始牌序｜點數｜花色
```

## 選牌與分墩

- 點擊手牌切換選取狀態。
- 可以同時選取多張牌，選取的牌會有黃色外框與編號。
- 最多同時選 5 張，避免誤選與畫面失去控制。
- 選取 3 張時，只啟用頭墩操作。
- 選取 5 張時，只啟用中墩與尾墩操作。
- 其他張數顯示還需要選幾張，不提供模糊的不可用按鈕。
- 一次放入後清空選取，並顯示「已放入頭／中／尾墩」。

操作列只在有選牌時顯示主要行動：

```text
已選 3 張      放入頭墩
已選 5 張      放入中墩／放入尾墩
```

## 墩位與修改

- 頭墩固定 3 張，中墩與尾墩固定 5 張。
- 已放入墩位的牌可以再次點選。
- 同一時間只選一個區域的牌，避免把手牌和不同墩位混成不明確的操作。
- 從墩位選取完整墩後，主要操作變成「退回手牌」。
- 退回後才能重新整理並放入其他墩位。
- 不使用拖曳作為唯一操作；拖曳可在未來作為桌面輔助，但手機點選流程必須完整。

## 即時回饋

畫面固定顯示一條短提示：

```text
先選 3 張牌組成頭墩，或選 5 張牌組成中／尾墩。
```

依選取數量改變：

```text
已選 2 張，再選 1 張即可放入頭墩。
已選 4 張，再選 1 張即可放入中墩或尾墩。
頭墩已完成：一對。
目前分墩不合法：中墩必須大於頭墩。
```

不在玩家畫面顯示 seed、節點 ID、測試用開發標籤。

## 手機版面順序

```text
敵人／目前目標
↓
三墩區：尾墩、中墩、頭墩
↓
選牌操作列
↓
排序列
↓
手牌
↓
確認這副牌
```

手牌是主要互動區，排序和分組按鈕靠近手牌；確認按鈕固定在底部，但只有 3／5／5 合法時才啟用。

## 驗收條件

- 排序不改變 13 張牌的 ID 集合。
- 相同 seed 的牌，三種排序都能回到同一組牌。
- 可以從手牌選 3 張一次放入頭墩。
- 可以從手牌選 5 張一次放入中墩或尾墩。
- 選 4 張時不會誤放入任何墩位，提示還需要 1 張。
- 已放入的完整墩可以一次退回手牌。
- 每次批次移動後都重新驗證 3／5／5 與墩位順序。
- 手機寬度下主要按鈕維持可觸控尺寸，不依賴拖曳。
